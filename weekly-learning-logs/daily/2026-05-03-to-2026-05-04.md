## Debugging Notes

The main lesson from these first sessions was that the issue is not always a lack of understanding. Sometimes the problem is that the code does not match the exact requirement.

Important debugging habits reinforced:

- Read the test failure carefully
- Check whether the variable being changed is the correct one
- Avoid changing values that the instructions expect to remain constant
- Confirm the expected output before assuming the logic is wrong
